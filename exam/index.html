提示:飽和度=顏色濃度;透明度=讓整頁看起來「淡淡的」效果;漸層深淺=拉小變淡(接近單色),拉滿是完整漸層(只對漸層主題有效);章節目錄統一色=左側各科分類的彩色邊框都改成主題色

⚠️ 不同 user 之間不共用 — 朋友來用你的網站，他要自己貼自己的 key（避免被吃額度）

🤖 Gemini API（給 AI 整理筆記用）

沒申請過 → 點這裡免費申請（5 分鐘、不用綁卡、每天 1500 次免費）

📷 GitHub 圖床（給筆記貼圖用）

筆記裡貼截圖會上傳到你自己的 GitHub repo（不吃本機容量、跨裝置共用）。
申請流程：點這裡生 token，照下面說明填寫。

📋 申請 Token 詳細步驟（點開看）
  1. Token name：隨便取，如 dental-notebook
  2. Expiration：選 Custom 設 1 年
  3. Repository access：選 Only select repositories → 選你的 repo
  4. Permissions 區塊 → 按右上角 + Add permissions → 搜尋並選 Contents
  5. 把 Contents 改成 Read and write（Metadata 會自動加，是正常的）
  6. 底部按 Generate token → 複製出來

不確定填什麼 → 留空也可以，貼圖功能會 disable
